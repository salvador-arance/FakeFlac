# ADR-0027: Classic desktop UI inspired by the reference tool: single window, folder tree, dense table and detail panel (docs/architecture/frontend.md)

- Status: accepted
- Date: 2026-10-15

## Context and rationale

It is what the owner asked for and it fits the 'drop, look, decide' flow. Reference screenshots are in docs/reference/.

## Decision

Classic desktop UI inspired by the reference tool: single window, folder tree, dense table and detail panel (docs/architecture/frontend.md).

## Alternatives considered

Modern web UI with page navigation; step-by-step wizard

## Consequences

Dense interface; accessibility needs care (RNF-08).
