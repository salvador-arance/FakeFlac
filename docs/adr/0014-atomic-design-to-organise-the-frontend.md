# ADR-0014: Atomic Design to organise the frontend

- Status: accepted
- Date: 2026-10-15

## Context and rationale

Shared vocabulary, reuse and specification by level (S6).

## Decision

Atomic Design to organise the frontend.

## Alternatives considered

Folders by technical type (components/hooks/utils); Feature-Sliced

## Consequences

Requires discipline to classify correctly; import rules are linted (scripts/lint-arch.mjs).
