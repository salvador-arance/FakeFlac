# ADR-0018: Progressive-disclosure context: short root CLAUDE.md + nested CLAUDE.md + linked docs/architecture

- Status: accepted
- Date: 2026-10-15

## Context and rationale

Context is limited and costly; each agent loads only what it needs.

## Decision

Progressive-disclosure context: short root CLAUDE.md + nested CLAUDE.md + linked docs/architecture.

## Alternatives considered

One long CLAUDE.md; no docs and let the agent explore the code

## Consequences

Links must be maintained and content must not be duplicated.
