# ADR-0029: SemVer, Conventional Commits and automatic changelog

- Status: accepted
- Date: 2026-10-15

## Context and rationale

Agents can apply it mechanically and the release notes write themselves.

## Decision

SemVer, Conventional Commits and automatic changelog.

## Alternatives considered

Date-based versions; manual changelog

## Consequences

The PR template and a check validate the title.
