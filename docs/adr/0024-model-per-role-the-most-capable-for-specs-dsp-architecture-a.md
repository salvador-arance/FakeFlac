# ADR-0024: Model per role: the most capable for specs, DSP, architecture and review; an intermediate one for implementation and tests; a light one for mechanical tasks

- Status: accepted
- Date: 2026-10-15

## Context and rationale

Balances quality and cost (R10).

## Decision

Model per role: the most capable for specs, DSP, architecture and review; an intermediate one for implementation and tests; a light one for mechanical tasks.

## Alternatives considered

The same model for everything

## Consequences

Configured with aliases in each subagent and reviewed when model generations change.
