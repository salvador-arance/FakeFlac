**Library census.** One command analyses a whole music folder with the same Rust pipeline as the app and prints the aggregate figures that the library diagnosis of 2026-11-14 had to compute by hand with throwaway scripts: verdicts per codec, the evidence behind the `Fake` verdicts, how the fakes are spread over albums, how far the lossless fakes are above their thresholds, the reasons of the `Suspicious` verdicts and the errors. The same command, run again after a detection change, shows what the change does to a real library, before it ships.

The census has no ground truth: it describes what the detector says, not whether it is right. Measuring the detector against known truth stays with RP-11 (`just accept`).

Measurable acceptance:

1. `just census FOLDER` analyses `FOLDER` with the scan, the analysis, the album grouping and the default `DetectionParams` of the app, and exits 0 when the run finishes, also when tracks have errors (RNF-04). `--params FILE` analyses with another params file.
2. It writes `summary.md` (aggregates only) and `tracks.csv` (one row per track, private) into `target/census/<run>/` inside the repository, and prints `summary.md` to stdout. It writes nothing else, and nothing into `FOLDER` (RNF-05).
3. `summary.md` holds no path, folder name or file name of `FOLDER` (ADR-0022), so it can be pasted into a PR.
4. On the census sample folder (synthetic fixtures, Unicode names, RNF-09), every figure of `summary.md` equals the expected one exactly. This runs in `just test` and in CI.
5. Two runs on an unchanged folder with the same build and params give a byte-identical `tracks.csv` and a `summary.md` that differs only in its `run:` line.
6. A missing or invalid argument, a folder that does not exist, a folder without supported audio, or an invalid params file exits 2 and writes nothing.
7. The recipe is opt-in: it is not part of `just check`, `just ci` or any workflow.

Source: the owner's library diagnosis of 2026-11-14 (`docs/agents/progress.md`, block "Library diagnosis"), which left "a repeatable library census recipe" as not specified.
