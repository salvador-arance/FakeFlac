---
id: RF-11
title: Cache results and reuse them when the file has not changed
priority: medium
milestone: H2
status: specified
---

Cache every track result in a local SQLite database, and reuse it instead of decoding the file again when the file is unchanged (same canonical path, size and modification time) and was analysed by the same engine (every `DetectionParams` value including `algorithm_version`, the decoder's extraction version and the app version). The cache is an optimisation that never changes a verdict and never fails a run. When it cannot be used, every file is analysed and the run's summary says so. The user can clear it from the toolbar. Measurable acceptance: a rerun on an unchanged folder makes no call to the audio decoder (counted through a spy of the `SpectrumAnalyzer` port), and its results and CSV equal the cold run's. A warm rerun of at least 200 tracks takes at most 10 % of the cold run's time (indicative, manual).
