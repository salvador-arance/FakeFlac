Interface in Spanish and English.

The owner selected **Spanish/English with a persistent language preference** in chat on
2026-11-01. The proposed feature translates every app-owned visible and accessible text,
provides a language-only Settings panel, and restores the saved language on the next launch.
Without a settings file, the initial language follows the first supported Windows user
language preference, falling back to English. A valid saved preference takes priority. A successful
Save updates the mounted interface without restarting or interrupting an analysis.

Advanced analysis settings (sampling windows, DetectionParams, custom parameter files), a
cache enable/disable switch and other preferences are deferred to a separate approved spec.
The historical planning document's larger Settings object is not the RF-13 payload.

Contract and G1 decisions: `specs/contracts/settings.md` (contract version 8, proposed).
UI and complete text catalogue: `specs/ui/language-settings.md` and
`specs/ui/translations.md`. Scenarios: `specs/features/language-settings.feature`.

Acceptance: every catalogue entry has explicit English and Spanish text and matching
placeholders; all mounted text and accessible names use the saved locale; a subsequent
process restores the saved language; settings failures leave analysis usable and preserve
the previous saved preference. The detailed automated and manual checks are in the UI spec.
