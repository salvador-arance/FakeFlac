**Comparative benchmark.** FakeFlac's accuracy is measured against comparable detectors on the same files, with the same truth and the same counting rules, so the project can state with evidence where it detects better or worse. RP-11 (`just accept`) measures FakeFlac against known truth. RP-12 (`just census`) describes a library without truth. Neither compares FakeFlac with other tools.

Comparable tools are named by letter only (tool A, tool B…) in the repository, issues and PRs (owner's decision, 2026-11-20). The owner keeps the mapping and the versions outside the repository.

Measurable acceptance (to be fixed at G1 of its spec):
- **Set.** A public, reproducible set generated by a script in the repository from openly licensed lossless sources, with known truth per case class: authentic lossless (CD rate and hi-res), lossy → lossless with and without the encoder low-pass, upsamples (RF-12), lossy → lossy at a higher bitrate (RF-15) including chains with no low-pass (RF-21), and damaged streams (RNF-12). The audio is never committed (ADR-0022). The owner's labelled corpus is run too, and reported as aggregates only.
- **Mapping.** Each tool's output maps to a common scale (`Real`, `Fake`, `Suspicious`, no verdict), fixed at G1 before any run. An output that does not map counts as no verdict.
- **Metrics.** Per case class and per tool: detection rate, false-positive rate on authentic lossless (the population and rule of the H3 target, #186), source-bitrate estimate within one table row (RF-15, RF-20), and share of files not analysed. Time per track is reported for information.
- **Fairness.** The same machine, default settings, versions recorded. Tools without a CLI are run by hand by the owner; a dev-only parser reads their exports (read-only, no network, RNF-03, RNF-05).
- **Runs.** A baseline on detection v8, and a final run on the default params of the H3 release. The report is aggregates only and can be pasted into a PR. The website (RNF-13) uses its figures.

Source: owner's decision of 2026-11-20 (H3, #184), after noting that no evidence says whether FakeFlac detects better or worse than the comparable tools. Issue #213.

Spec: pending (`/new-spec RP-13`). Open questions in #213: which openly licensed sources, whether published results name the tools (after checking that each tool's licence allows publishing benchmark results), and the manual time budget per run. An ADR if the generation script needs a new dependency or an encoder that the tests do not already use.
